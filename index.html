☁️ ออนไลน์ผ่าน Google Drive ทุกเครื่อง/มือถือเห็นข้อมูลเดียวกัน

ใน Drive มีข้อมูลปี 64–69 รวมหลายพันไฟล์ ดึงเฉพาะช่วงที่ใช้ — ครั้งแรกใช้เวลาราว 1–2 วินาที/ไฟล์ ครั้งต่อไปดึงเฉพาะไฟล์ใหม่
วิธีตั้งค่า (ทำครั้งเดียว ~5 นาที)
  1. ✅ ซิงค์โฟลเดอร์ D:\งานข้อมูล LPR ขึ้น Google Drive แล้ว
  2. ล็อกอินบัญชี Google ที่เป็นเจ้าของโฟลเดอร์ แล้วเปิด script.google.com → โครงการใหม่
  3. ลบโค้ดเดิมในหน้า Code.gs ทั้งหมด → วางโค้ดจากไฟล์ Code_LPR_v2.gs → กด 💾 บันทึก (รหัสโฟลเดอร์ใส่ไว้ในโค้ดแล้ว)
  4. เลือกฟังก์ชัน testSetup → กด เรียกใช้ (Run) → อนุญาตสิทธิ์ (ขั้นสูง → ไปที่โครงการ) → ดูบันทึกว่าพบไฟล์
  5. การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ → ⚙️ เลือก เว็บแอป · เรียกใช้ในฐานะ: ฉัน · ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน → Deploy → คัดลอก URL ที่ลงท้าย /exec มาวางด้านบน
  6. กด "ทดสอบการเชื่อมต่อ" → "ซิงค์ข้อมูลตอนนี้"
